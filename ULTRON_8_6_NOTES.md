# ULTRON 8.6 — Cross-platform upgrade notes

This update preserves the supplied ULTRON 8.5 Android source and adds a shared Java 17 core and Windows/Linux desktop foundation. It does not include macOS.

See `docs/ULTRON_8_6_STATUS.md` for the precise implemented and incomplete feature list, build instructions, and verification limitations.

Version: Android `8.6.0` / versionCode `86`.
