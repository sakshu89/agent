# ITRA — Intelligent Task & Reasoning Agent

**ITRA is built from the supplied Android ULTRON codebase and integrates Hermes Agent 0.23.1 through an optional local companion bridge.**

Start with [`ITRA_README.md`](ITRA_README.md) for the project architecture and [`agent-engine/README.md`](agent-engine/README.md) for Hermes setup. Historical ULTRON release notes and architecture documents are retained for provenance.

The Android package ID remains `com.ultron.app` intentionally, preserving upgrade compatibility with the existing installed app and its local data. The visible app identity and wake phrase are ITRA.
