# Build ULTRON 8.0 with GitHub Actions

## Fastest method

1. Create a GitHub repository.
2. Upload **all files and folders** from this project into the repository root.
3. Make sure these are at the root:
   - `settings.gradle.kts`
   - `build.gradle.kts`
   - `gradlew`
   - `gradle/wrapper/gradle-wrapper.jar`
   - `gradle/wrapper/gradle-wrapper.properties`
   - `app/`
   - `.github/workflows/build.yml`
4. Push to the `main` branch.
5. Open **GitHub → Actions → ULTRON 8.0 Android Build**.
6. Wait for `Build debug APK` to finish.
7. Open the workflow run and download **ULTRON-8.0-debug-apk** from Artifacts.

## Manual build from GitHub

The workflow can also be started from:

**Actions → ULTRON 8.0 Android Build → Run workflow**

## Important

The repository does **not** need Android Studio or a locally installed Gradle. GitHub Actions uses the Gradle wrapper committed in this repository and installs the required Android SDK packages.

The debug APK is generated by:

```text
app/build/outputs/apk/debug/
```

The workflow also creates an unsigned release APK artifact. It is not a production-signed APK.

## API configuration

Do not commit private API keys. Configure secrets/environment variables if a future cloud provider is added. The current project keeps the local LLM base URL in `BuildConfig` and does not contain a private API key.

## Vosk

Import a compatible Vosk model through ULTRON's model-management flow as documented by the app. Do not commit a large model ZIP unless you intentionally want it in the repository.

## If GitHub reports a Gradle/dependency error

Open the failed workflow run and copy the **first meaningful Gradle error**, not the final stack-trace summary. That error is the useful diagnostic.
