# ULTRON 10.0

ULTRON 10.0 consolidates the existing Android assistant, shared Java 17 agent core and Windows/Linux desktop foundation without replacing the ULTRON architecture.

Read in this order:
1. `docs/ULTRON_10_0_RELEASE.md` — scope, architecture, setup, validation and limitations.
2. `docs/ULTRON_10_0_SECURITY.md` — safety and privacy boundaries.
3. `docs/ULTRON_10_0_PLATFORM_MATRIX.csv` — capability-by-platform status.
4. `docs/ULTRON_10_0_DEPENDENCIES.md` — direct dependency/license review checklist.
5. `docs/ULTRON_10_0_BUILD_REPORT.md` — build verification status.
